# Security Policy

## Supported versions

This is a desktop application distributed as source. Please use the latest commit on the default branch.

## Reporting a vulnerability

If you discover a security issue (for example, unsafe handling of local files or dependencies):

1. **Do not** open a public GitHub issue with exploit details.
2. Contact the repository maintainers privately (GitHub Security Advisory if enabled, or email listed on the repo profile).
3. Allow reasonable time for a fix before public disclosure.

## Notes for users

- The app runs **locally**. It does not require an account.
- Text-to-speech may contact Microsoft Edge online voices (`edge-tts`) or Google (`gTTS`) when generating audio.
- Do not place secrets in project files; none are required for basic use.
